#### Personal server
This is my passion project, consisting of a bare metal proxmox installation, administering services for me and my family.
To name a few:
- Technitium DNS + Unbound - Authoritative and recursive self hosted DNS solutions that keep dns traffic internal and secure
- Adguard + PiHole - Mainly ad blocking and also acting as DHCP server for the network (!Planning on migrating to a pfSense capable machine and moving DHCP there!)
- Webmin + SMB/NFS Modules - Centralized storage management, securely exposing ZFS backed storage via SMB and NFS over LAN as well as private VPN networks
- MySQL/MariaDB + PostgreSQL - RDBMS that aggregate and store data from other services, most notably Bookstack
- Bookstack - THE most essential service of all, holds documentation of the server and each service separately
- Jellyfin + Navidrome - Media servers for accessing personal library
  - Full workflow contains ABCDE (audio cd ripping), Handbrake (video cd/dvd ripping), tinyMediaManager (movie/show management and scraping), musicBrainz Picard (audio library management and scraping)
- Many many more
